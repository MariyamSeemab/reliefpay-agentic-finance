# Archive

These are the planning documents from the first frontend-only version of ReliefPay (October 2026): the original requirements, the frontend handoff notes and the planned backend spec.

They are kept for history and are **out of date**. Several describe features as planned or mocked that are now built differently, and the old API reference lists endpoints that were never implemented.

For the current project see:

- [README](../../README.md): features, setup, architecture and tools
- [API reference](../API.md): the routes that actually exist
